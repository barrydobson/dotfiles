# Ticketing

The ticketing rules live in the `to-tickets` and `to-spec` skills, which only the user can start. Before writing a ticket by hand, read `~/.claude/plugins/cache/barrydobson/barrydobson-skills/*/skills/to-tickets/SKILL.md` (newest version) and follow it.

When a ticket touches a repo that is not open in this session, read it with a read-only `hc` agent in that repo, or an Explore agent.
